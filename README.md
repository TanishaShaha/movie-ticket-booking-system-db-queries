## 🎬 Movie Ticket Booking System - Database Queries<br>

This repository contains SQL scripts and queries used in the Movie Ticket Booking System, a project designed to manage and process movie ticket reservations efficiently.


### 📚 About the Project

- Handles movie listings, theaters, showtimes, bookings, and customer details.
- Provides queries for:
  - Adding new movies and theaters
  - Searching available shows
  - Booking and canceling tickets
  - Retrieving booking details and reports
- Designed for learning and practicing SQL database design and query writing.
